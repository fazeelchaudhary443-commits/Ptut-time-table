# PTUT Hub — Student Platform

A frontend-first prototype for a Punjab Tianjin University of Technology student platform.

## Current prototype
- Responsive student dashboard
- Timetable
- Tasks with local persistence
- Exams
- Announcements
- Profile
- Mobile/PWA-ready structure
- Responsive sidebar/navigation

## Next production steps
1. Create Supabase project.
2. Add authentication.
3. Replace local demo data with PostgreSQL tables.
4. Add admin dashboard and role-based access.
5. Add real PTUT timetable/section data.
6. Add push notifications.
7. Package the mobile experience with Expo/React Native.

This prototype intentionally contains no real student data and no external API credentials.


## PTUT Color Edition
This edition keeps the original PTUT Hub prototype layout, components, spacing, and interactions.
Only the visual color palette has been adapted to PTUT-inspired green, red, blue, and white tones.
